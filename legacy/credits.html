Built on open source

None of my projects would exist without software that other people wrote and gave away. These are the open source projects I rely on, and what each one does for me.

Smart home and automations

  • Home AssistantThe automation platform everything meets in.
  • Zigbee2MQTTBridges my Zigbee buttons and sensors into Home Assistant.
  • ratgdoThe board that puts my garage door opener on the local network.
  • Frigate notifications blueprint by SgtBattenThe blueprint behind my phone and TV camera alerts.

Cameras and AI

  • FrigateCamera recorder with local object detection, face recognition and semantic search.
  • ScryptedThe camera bridge that made my doorbell stream stable.
  • MediaMTXThe stream relay I tested as an alternative bridge.

Displays and dashboard

  • Advanced Camera CardThe camera grid on the tablet and TV.
  • card-modLets me style cards, including the garage warning banner.
  • Browser ModLets automations navigate the TV's browser.
  • hui-elementPlaces full cards inside a picture layout.
  • Kiosk ModeHides the Home Assistant menus on the wall tablet.
  • Immich KioskThe photo slideshow the displays return to.

Server and services

  • Docker (Moby)The container engine every service runs on.
  • ImmichSelf-hosted photo library.
  • NextcloudSelf-hosted file sync.
  • JellyfinMedia server with hardware transcoding.
  • PostgreSQLThe database behind the photo library.

Remote access

  • frpThe tunnel between the cloud relay and my server.
  • Nginx Proxy ManagerThe reverse proxy on the cloud relay.
  • TailscalePrivate access between my own devices. The client is open source.

Robot boat

  • rpicam-appsThe Raspberry Pi camera tools my script reads detections from.
  • Raspberry Pi IMX500 modelsSource of the MobileNet-SSD model that runs on the camera.
  • PythonThe navigation script.
  • pySerialSerial link from the Pi to the Arduino.
  • ArduinoThe motor controller's board and toolchain.

I also use some software that is not open source, including Unraid as the server operating system and Fully Kiosk Browser on the wall tablet.

The app icons in the home server diagram come from the open source Dashboard Icons collection. Each logo belongs to its own project.

If I have missed a project or described it wrongly, the fault is mine. Each name above belongs to its own authors and community.
